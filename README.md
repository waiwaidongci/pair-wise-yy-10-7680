# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

## 闭环

- **入坊体检**：登记来源、含水率、壁厚差、裂纹数、接收人。含水率、壁厚差两项任一超限即转入养护区，暂不占用贴线材料和工位；两项均合格进入待领队列；两项测量值都留空则进「待体检」待补（只填一项会被拦回，避免半套数据误判）。
- **领料台**：合格作品按排队时间列出，领料后才占用贴线材料与工位（容量条实时显示），贴线进度从 0% 起计；完工转待阴干时释放材料与工位。养护区/待体检作品不占任何资源。
- **领料后体检值更正**：在「贴线中」卡片点「更正体检值」，须二次勾选确认。确认后贴线进度与材料/工位占用立即失效，作品回到「待体检」，旧体检值与原贴线进度以快照形式留在履历（含初检/复测来源、操作人、时间），重新体检合格后才能再排队领料。
- **养护复测**：复测人不能与初检接收人为同一人；含水率、壁厚差两项都达标才重新进入待领队列，任一超限继续养护。看板「养护区」卡片标出当前卡点，并并列展示初检与最近复测两次测量值。
- 裂纹数只登记与展示，不作为超限判定项。
- 判超限标准（含水率上限、壁厚差上限）可在领料台右下角调整，持久化保存。

## 其他能力

- 看板七列：待体检、待领料、养护区、贴线中、待阴干、上金粉、待交付。
- 今日待阴干、养护区卡点、缺陷作品、最近交付四类列表。
- 可更新状态、改进度、记录断线/翘线、查看含履历时间线的作品详情。
- 支持筛选、排序、localStorage 持久化和 JSON 导出；旧版本地数据自动迁移。
