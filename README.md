# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

已实现闭环：
- 入坊体检与领料台：登记来源、含水率、壁厚差、裂纹数和接收人；含水率 ≤ 12%、壁厚差 ≤ 1.5mm 达标进待领料，超限进养护区，暂不占贴线材料与工位。
- 待领料作品领料后才占用材料与工位并进入贴线中。
- 领料后更正体检值：贴线进度与占用失效，作品退回待体检，旧值与原进度保留在履历。
- 养护后由另一人复测（校验复测人 ≠ 初测接收人），含水率与壁厚差两项达标才重新排队待领料。
- 看板覆盖待体检、养护区、待领料、贴线中、待阴干、上金粉、待交付，卡片标出卡点与初测/复测两组测量值。
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 今日待阴干、养护区卡点、缺陷作品、最近交付四类列表。
- 可更新状态、记录断线/翘线、查看作品详情与流转履历。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。
